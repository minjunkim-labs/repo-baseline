# v2.3.0

v2.2.0 뒤 `changelog.d/`에 쌓인 항목을 모은 것이다. 코어 `REVIEW.md` 관리 블록과 PR 템플릿 Evidence가 바뀌고 v1 도구를 지워 minor를 올린다. 판 올리기는 [docs/start.md](../start.md) 「판 올리기」대로 `python3 -I .baseline/baseline.py upgrade v2.3.0`이다. 관리 블록·파일은 `upgrade`가 바꾸므로 손으로 옮길 일은 거의 없다.

- 이 저장소만: `check.yml`의 `self` job이 태그를 받는다. 루트를 다음 태그로 `upgrade`한 뒤부터 CI도 루트 사본을 그 태그와 바이트로 비교한다. 그 전에는 지금처럼 건너뛴다. 소비 레포가 옮길 일은 없다.
- 코어 `REVIEW.md`의 Standards가 원인 없이 다시 돌려 통과시킨 테스트와 까닭 없이 지운 테스트를 실패로 본다. `upgrade`로 관리 블록이 바뀐다. `prompts/retro.md`는 새 검사를 최근 PR의 head에서 먼저 돌려 보이게 한다. 손으로 옮길 일은 없다.
- v1 도구(`templates/`, `profiles/`, `tools/`)를 지웠다. Dependabot·`SECURITY.md`·`.coderabbit.yaml` 원본은 `github/`로 옮겼고, pstack 절과 Linear 규칙은 `WORKFLOW.md`에 있다.
  소비 레포가 옮길 일은 없다. 루트 `.coderabbit.yaml` 첫 줄 주석의 원본 경로만 `github/.coderabbit.yaml`로 바뀌었다(동작은 같다).
- PR 템플릿 Evidence에 「실행 확인:」 줄이 생긴다(`upgrade`로 바뀐다). 실행할 수 있는 동작을 바꾼 PR은 그 동작을 직접 돌려 본 방법과 결과를, 아니면 `없음: <이유>`를 쓴다. 이미 열린 PR 본문은 손으로 그 줄을 더한다.
