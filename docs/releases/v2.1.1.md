# v2.1.1

v2.1.0 뒤 `changelog.d/`에 쌓인 항목을 모은 것이다. 코어 동작의 버그 수정만 있어 patch를 올린다. 판 올리기는 [docs/start.md](../start.md) 「판 올리기」대로 `python3 -I .baseline/baseline.py upgrade v2.1.1`이다.

- `migrate`가 `AGENTS.md`에 `- 상시 지시:` 줄이 없으면 코어의 「병합」 절을 관리 블록 앞에 더한다. v2.1.0으로 이 줄 없이 옮긴 소비 레포는 코어 `AGENTS.md`의 「병합」 절을 손으로 옮긴다(answer-desk·portfolio·mobile-runtime·smallnext·BGLike는 이미 옮겼다). 큐를 끄려면 그 줄을 지운다.
- `review-preflight --json`의 키 `secret_hits`를 `env_file_hits`로, 함수 `secret_names`를 `env_file_names`로 바꿨다. CodeQL `py/clear-text-logging-sensitive-data`가 `.env` 파일 경로 출력을 비밀값 출력으로 짚던 경고 4건이 사라진다. 이 키를 읽는 스크립트가 있으면 이름을 바꾼다. 이미 오탐으로 닫은 경고는 그대로 둔다.
- ops 프로필 검사가 `.env.example`의 stat이 막힌 경우(`.env.*`를 막는 sandbox, Python 3.15의 `Path.exists()`)를 "파일 없음"으로 보고 통과하던 것을 고쳤다. 이제 그 파일을 읽지 못했다고 실패한다. 소비 레포가 옮길 일은 없다.
- 이 저장소만: `AGENTS.md` 길잡이 표에 `GLOSSARY.md`·`changelog.d/`를 더했다. `check.yml`의 자체 검사를 job `self`로 빼 v2와 함께 돌리고 `push: main` 트리거를 지웠다. `GLOSSARY.md`에 모델 층·effort·층 표를 더하고 ADR 0002를 썼다. 소비 레포가 옮길 일은 없다.
