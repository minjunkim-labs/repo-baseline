# v2.4.1

v2.4.0 뒤 `changelog.d/`에 쌓인 항목을 모은 것이다. 소비 레포가 옮길 파일이 `github/enqueue.yml` 하나뿐인 보완이라 patch를 올린다. 판 올리기는 [docs/start.md](../start.md) 「판 올리기」대로 `python3 -I .baseline/baseline.py upgrade v2.4.1`이다. `baseline.py`는 `VERSION` 한 줄만 바뀌고, workflow 파일은 `upgrade`가 바꾸지 않으므로 아래처럼 손으로 다시 복사한다. 이 복사를 `upgrade` PR과 같은 PR에 넣으면 그 PR은 upgrade 예외를 잃고 어려움이 되므로, `upgrade` PR을 쉬움으로 두려면 따로 낸다.

- `github/enqueue.yml`: 댓글 작성자가 OWNER·MEMBER·COLLABORATOR(`author_association`)일 때만 job이 돈다(공개 저장소에서 아무나 `/enqueue` 댓글로 실행과 거절 댓글을 쌓지 못하게). `concurrency` group을 PR 번호에서 댓글 id로 바꿨다(같은 PR에 요청이 연달아 오면 대기 중이던 요청이 취소돼 답이 없던 것을 막는다). v2.4.0의 `.github/workflows/enqueue.yml`을 쓰는 소비 레포는 이 파일을 새 판으로 다시 복사한다. `.github/workflows/**`라 어려움 PR이고 소유자가 병합한다.
