# v2.0.1

v2.0.0 뒤 `changelog.d/`에 쌓인 항목을 파일 이름 순서로 모은 것이다. 판 올리기는 [docs/start.md](../start.md) 「판 올리기」대로 `python3 -I .baseline/baseline.py upgrade v2.0.1`이다. 손으로 옮길 일은 CodeRabbit 설정 하나다.

- WORKFLOW.md 「실행 위치마다 적용되는 것」을 두 축(내 기기·클라우드, 세션 하나·여럿)으로 다시 짰다. Claude 클라우드는 `gh pr`·`gh issue`(GraphQL)와 태그 push를 거부하므로 스펙·티켓 단계와 태그는 내 기기에서 한다. 소비 레포가 옮길 일은 없다.
- CodeRabbit 자동 리뷰를 끈다(`reviews.auto_review.enabled: false`). `templates/github/.coderabbit.yaml`을 그대로 복사한 저장소는 새 파일로 다시 복사하고, 합친 저장소는 그 키를 더한다. 어려움 PR에서는 리뷰어가 `@coderabbitai review`로 한 번 요청한다.
- WORKFLOW 「단계별 스킬」: 사람만 부르는 pstack 스킬에 (사람)을 붙이고, spec Issue는 상태 라벨 없이 두고 마지막으로 병합하는 티켓 PR이 닫는다고 적었다. 막힘이 없는 티켓은 세션을 나란히 띄운다. POLICY: fork PR은 소유자가 큐에 넣고, PR 없이 남은 원격 브랜치는 내용이 `main`에 있는지 보고 지운다. 소비 레포가 옮길 일은 없다.
